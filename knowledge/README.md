# پایگاه دانش — شرکت دیجیتال مارکتینگ و طراحی سایت شما

این پوشه برای **خدمات و نمونه‌کارهای شرکتِ شما** است.

دستیار مهارتِ **ترغیب به خدمات** را از `prompts/sales_playbook.md` می‌گیرد؛ جزئیاتِ خودت (خدمات، تعرفه‌ی حدودی، نمونه‌کار، FAQ) را اینجا بگذار تا وقتی مشتری پرسید دقیق جواب بده و راحت‌تر تبدیل شه.

### چی بذارم اینجا؟ (هر موضوع یه فایلِ کوتاهِ `.md`)
- `services.md` — لیست خدمات: طراحی سایت شرکتی/فروشگاهی/اختصاصی، سئو، گوگل ادز، اینستاگرام، تولید محتوا، برندینگ، پشتیبانی
- `portfolio.md` — ۳-۴ نمونه‌کار با «قبل و بعد» (مثلا: سایت فروشگاهی X — سرعت ۲×، فروش ۳×)
- `pricing.md` — بازه‌ی قیمت یا «از X تومان» (نه قیمت نهایی — اون تو مشاوره)
- `faq.md` — سوال‌های پرتکرار: «سایت چقدر طول می‌کشه؟»، «سئو کی جواب می‌ده؟»، «پشتیبانی دارید؟»
- `process.md` — فرآیندِ همکاری: مشاوره رایگان → پروپوزال → اجرا → تحویل → پشتیبانی

> نکته: جزئیاتِ حساس (قیمت نهایی، لاگین) رو اینجا نذار — دستیار فقط کلیات رو بگه و بکشه سمتِ مشاوره.

### چطور فعال کنم؟
```powershell
# 1. فایل‌ها رو بریز اینجا
# 2. ایندکس بساز
python scripts/build_rag_index.py
# 3. روشن کن
# در .env: RAG_ENABLED=true
# ری‌استارت: python agent.py dev
```

تست:
```powershell
python scripts/build_rag_index.py --query "طراحی سایت فروشگاهی چقدره؟"
python scripts/check_retrieval.py
```

> دستیار بدونِ این پوشه هم کار می‌کنه (عمومی ترغیب می‌کنه)، ولی با این اسناد **دقیق و قابل اعتماد** می‌فروشه.
