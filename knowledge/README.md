# پایگاه دانش

این پوشه برای اسناد **سازمان شما** است — نه نمونه‌ی آماده.

دستیار **هیچ اطلاعات محصولی** از پیش ندارد و نباید داشته باشد. مهارت او در **فروش حرفه‌ای و دیجیتال مارکتینگ** است، نه حفظ کردن کاتالوگ.

اگر می‌خواهی دستیار به اسناد داخلی‌ات دسترسی داشته باشد:

1. فایل‌های `.md` یا `.txt` را اینجا بگذار (هر موضوع یک فایل کوتاه)
2. ایندکس را بساز:

```powershell
python scripts/build_rag_index.py
```

3. در `.env` بگذار `RAG_ENABLED=true` و ایجنت را ری‌استارت کن.

نمونه‌ی کاربرد:
- راهنمای برند و لحن سازمان
- پاسخ‌های متداول (FAQ)
- فرآیندهای داخلی
- محتوای آموزشی که می‌خواهی دستیار بر اساس آن مشاوره دهد

> توجه: اطلاعات محصول، قیمت، موجودی و تخفیف نباید در سورس بماند. اگر چنین داده‌ای داری، از دیتابیس یا API لود کن — نه فایل استاتیک در ریپو.

برای تست کیفیت بازیابی:

```powershell
python scripts/build_rag_index.py --query "سوال نمونه"
python scripts/check_retrieval.py
```
