# پایگاه دانش نمونه

این پوشه جای اسناد واقعی سازمان است. ایجنت هر فایل `.md`، `.txt` یا `.rst` را
در این پوشه (و زیرپوشه‌هایش) ایندکس می‌کند.

دو فایل نمونه اینجا هست تا بتوانید بلافاصله امتحان کنید. بعد از اینکه اسناد
خودتان را گذاشتید، این دو فایل را پاک کنید و ایندکس را دوباره بسازید:

```powershell
python scripts/build_rag_index.py
```

## نکته‌ها

- عنوان‌های `#` و `##` به هر تکه برچسب منبع می‌دهند؛ بدون عنوان، منبع فقط نام فایل است.
- هر پاسخ بر اساس متن بازیابی‌شده ساخته می‌شود، پس متن را روشن و بدون ضمیر مبهم بنویسید
  («او باید...» به «کارمند باید...» تبدیل شود).
- هرچه فایل‌ها کوچک‌تر و موضوعی‌تر باشند، بازیابی دقیق‌تر است.
