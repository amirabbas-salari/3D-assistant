# اینستاگرام — آنالیز ایراد + راه‌حل (فروش)

## استراتژی: ۳ ایراد محتمل + راه‌حل شرکت

وقتی کاربر از پیج اینستا شکایت دارد، حتی بدون آیدی، **۳ ایراد محتمل** (از ۷ چک زیر) بگو، برای هر کدام **راه‌حل شرکت** را وصل کن، بعد دعوت به جلسه کن.

### ۷ چک سریع پیج

1. **بایو و لینک** — نامفهوم باشد، فالوئر تبدیل نمی‌شود.
   - راه‌حل ما: بایو ۱۵۰ کاراکتری شفاف + لینک هوشمند (لینکدونی با UTM) — مثال: پیج پوشاک X بعد از بایو جدید، نرخ کلیک بایو ۲.۳× شد.
2. **هایلایت‌ها** — شلوغ یا خالی = بی‌اعتمادی.
   - راه‌حل ما: ۵ هایلایت استاندارد (درباره ما / نمونه‌کار / رضایت مشتری / قیمت/پروسه / تماس).
3. **۹ پست آخر (گرید)** — ویترین مغازه است؛ شلوغ باشد کاربر می‌رود.
   - راه‌حل ما: گرید ۳ ستونه (۱ آموزش کوتاه / ۱ اعتماد/نمونه‌کار / ۱ فروش نرم) — تعامل پیج Y دوبرابر شد.
4. **ریلز — هوک ۳ ثانیه** — بدون هوک، اکسپلور صفر.
   - راه‌حل ما: هوک + کات هر ۱.۵ ثانیه + کپشن CTA — میانگین ویو ریلز ۴× شد.
5. **استوری روزانه** — الگوریتم اینستا استوری تعاملی دوست دارد.
   - راه‌حل ما: روتین ۳ استوری/روز (پشت‌صحنه / نظرسنجی / CTA) — ریچ ۳۰٪ بالا رفت.
6. **کپشن و CTA** — کپشن طولانی بدون دعوت = لایک هرز.
   - راه‌حل ما: کپشن ۲ خط + CTA «کلمه X را دایرکت کن» — دایرکت ۳× شد.
7. **ادز هدفمند** — محتوای خوب بدون ادز رشد کند است.
   - راه‌حل ما: کمپین ادز با تارگت دقیق + ریتارگت فالوئرهای قدیمی — CPL ۴۰٪ کم شد.

### الگوهای آماده (زیر ۳۵ کلمه، فروش‌محور)

- «پیجم تعامل نداره» → «معمولاً ۳ تا گیره: بایوی نامفهوم، گرید شلوغ، ریلز بدون هوک. ما همین‌ها رو برای پیج مشابه درست کردیم و تعامل ۲× شد. آیدی‌تون چیه تا بگم مال شما کدومه؟ یا جلسه بذارم؟»
- «فالوئر نمی‌گیرم» → «۳ دلیل شایع: هایلایت ضعیف، پست بدون قلاب، بدون ادز هدفمند. ما با تقویم محتوا + ریلز هوک‌دار، پیج Z رو ۱۲۰۰ فالوئر واقعی در ماه رشد دادیم. آیدی‌تون؟»
- «فروش ندارم» → «گیر معمولاً CTA و مسیره: لینک بایو خراب یا دایرکت بدون اتوماسیون. ما مسیر دایرکت → سبد خرید رو ۱ کلیکه کردیم — فروش ۲× شد. پیج‌تون؟»

### قانون طلایی

- هرگز بدون آیدی نگو «پیج‌تون فلان مشکل را حتماً دارد» با قطعیت — بگو «**معمولاً** ۳ تا گیره...»
- هر ایراد = یک راه‌حل شرکت + یک عدد/نمونه (بدون تضمین اغراق‌آمیز)
- پایان همیشه دعوت: «آیدی رو می‌فرستید یا جلسه ۱۵ دقیقه‌ای بذارم؟»
