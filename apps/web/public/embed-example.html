این یک سایت نمایشی است

گوشه‌ی پایین (چپ/راست) دکمه‌ی شناور سام را می‌بینید. روی آن کلیک کنید — دستیار صوتی در پاپ‌آپ باز می‌شود. همین یک خط کد به سایت اصلی‌تان اضافه کنید:

<script src="https://sam.yourdomain.com/widget.js" data-sam-url="https://sam.yourdomain.com" data-sam-color="#244f91" async></script>

نکته برای تست لوکال: اگر دستیار روی http://localhost:3001 اجراست، این فایل را با
data-sam-url="http://localhost:3001" باز کنید و با npm run dev بالا باشید.
